# 模块7: 资产管理模块详细设计

## 功能清单

| 功能点 | 说明 | 优先级 |
|--------|------|--------|
| 资产登记 | 记录资产信息 | P1 |
| 资产领用 | 在线申请领用 | P1 |
| 资产归还 | 记录归还信息 | P1 |
| 资产调拨 | 跨部门调拨需审批 | P2 |
| 资产盘点 | 定期盘点，生成报告 | P2 |
| 资产报废 | 记录报废原因，审批 | P2 |
| 资产统计 | 统计资产分布 | P2 |

## 数据模型

- Asset - 资产
- AssetBorrow - 领用
- AssetReturn - 归还
- AssetTransfer - 调拨
- AssetScrap - 报废
