# 模块3: 审批流程模块详细设计

## 1. 功能概述

审批流程模块是OA系统的核心模块，用于处理各类审批业务，包括请假、加班、报销等申请的审批流转。

**注意**：移动端功能本次不实现。

## 2. 功能清单

| 功能点 | 说明 | 优先级 |
|--------|------|--------|
| 流程模板管理 | 可视化流程设计器，支持串行、并行、分支、条件分支 | P1 |
| 我的申请 | 提交审批申请，查看申请记录和进度 | P1 |
| 待我审批 | 审批人可审批、驳回、转交、委派、加签 | P1 |
| 我已审批 | 查看历史审批记录 | P2 |
| 审批抄送 | 审批完成后自动抄送相关人员 | P2 |
| 催办提醒 | 超时未审批自动提醒，支持手动催办 | P2 |
| 审批统计 | 统计各部门审批时效、驳回率等数据 | P2 |

## 3. 现有数据模型

已存在的表和实体：
- `approval_request` - 审批请求表
- `approval_task` - 审批任务表
- `approval_node` - 审批节点表
- `process_definition` - 流程定义表

## 4. 数据模型设计

### 4.1 审批操作记录表 (approval_operation)

```sql
CREATE TABLE approval_operation (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    task_id BIGINT NOT NULL COMMENT '任务ID',
    operator_id BIGINT NOT NULL COMMENT '操作人ID',
    operation_type VARCHAR(20) NOT NULL COMMENT '操作类型: approve-批准, reject-驳回, transfer-转交, delegate-委派, add_sign-加签',
    comment VARCHAR(500) COMMENT '审批意见',
    target_user_id BIGINT COMMENT '转交/委派目标用户ID',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 4.2 审批抄送表 (approval_cc)

```sql
CREATE TABLE approval_cc (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    request_id BIGINT NOT NULL COMMENT '审批请求ID',
    user_id BIGINT NOT NULL COMMENT '被抄送人ID',
    is_read TINYINT(1) DEFAULT 0 COMMENT '是否已读',
    read_time DATETIME COMMENT '阅读时间',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 4.3 催办记录表 (approval_reminder)

```sql
CREATE TABLE approval_reminder (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    request_id BIGINT NOT NULL COMMENT '审批请求ID',
    task_id BIGINT COMMENT '任务ID',
    reminder_user_id BIGINT NOT NULL COMMENT '催办人ID',
    reminder_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '催办时间',
    reminder_count INT DEFAULT 1 COMMENT '催办次数',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP
);
```
