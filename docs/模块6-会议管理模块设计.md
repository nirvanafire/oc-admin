# 模块6: 会议管理模块详细设计

## 1. 功能概述

会议管理模块用于企业会议室预约、会议通知、签到和纪要管理。

## 2. 功能清单

| 功能点 | 说明 | 优先级 |
|--------|------|--------|
| 会议室管理 | 维护会议室信息，支持可视化预约状态 | P1 |
| 会议预约 | 选择会议室、时间、参会人，系统自动检查冲突 | P1 |
| 会议通知 | 预约成功后自动发送通知 | P2 |
| 会议签到 | 扫码签到，记录参会人员 | P2 |
| 会议纪要 | 支持上传附件、记录纪要 | P2 |
| 会议统计 | 统计会议室使用率、会议时长 | P2 |

## 3. 数据模型

- MeetingRoom - 会议室
- MeetingReservation - 会议预约
- MeetingAttendee - 参会人
- MeetingMinutes - 会议纪要

## 4. API设计

| 方法 | 路径 | 说明 |
|------|------|------|
| GET/POST | /api/meeting/rooms | 会议室CRUD |
| GET/POST | /api/meeting/reservations | 会议预约 |
| GET | /api/meeting/reservations/{id}/qrcode | 签到二维码 |
| POST | /api/meeting/reservations/{id}/checkin | 会议签到 |
| POST | /api/meeting/reservations/{id}/minutes | 添加会议纪要 |
| GET | /api/meeting/statistics | 会议统计 |
