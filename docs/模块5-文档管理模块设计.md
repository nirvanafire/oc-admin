# 模块5: 文档管理模块详细设计

## 1. 功能概述

文档管理模块用于企业文档的集中管理，支持文件夹结构、文件上传下载、在线预览、版本管理、共享和搜索功能。

## 2. 功能清单

| 功能点 | 说明 | 优先级 |
|--------|------|--------|
| 文档库 | 树状文件夹结构，创建/移动/重命名/删除文件夹 | P1 |
| 文档上传 | 拖拽上传、批量上传，限制文件大小和格式 | P1 |
| 文档预览 | 在线预览Word/Excel/PPT/PDF/图片 | P2 |
| 文档编辑 | 在线编辑，版本管理，可回滚历史版本 | P2 |
| 文档共享 | 设置共享范围（部门/个人/公开），下载/打印权限 | P1 |
| 文档搜索 | 按文件名、内容、标签搜索，高级搜索 | P2 |

## 3. 数据模型设计

### 3.1 文档文件夹表 (document_folder)

```sql
CREATE TABLE IF NOT EXISTS document_folder (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    parent_id BIGINT DEFAULT 0 COMMENT '父文件夹ID，0为根目录',
    name VARCHAR(100) NOT NULL COMMENT '文件夹名称',
    owner_id BIGINT NOT NULL COMMENT '所有者ID',
    owner_name VARCHAR(100) COMMENT '所有者姓名',
    is_public TINYINT(1) DEFAULT 0 COMMENT '是否公开',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_parent_id (parent_id),
    INDEX idx_owner_id (owner_id)
);
```

### 3.2 文档文件表 (document_file)

```sql
CREATE TABLE IF NOT EXISTS document_file (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    folder_id BIGINT NOT NULL COMMENT '文件夹ID',
    file_name VARCHAR(200) NOT NULL COMMENT '文件名称',
    file_size BIGINT COMMENT '文件大小（字节）',
    file_type VARCHAR(50) COMMENT '文件类型',
    file_path VARCHAR(500) COMMENT '存储路径',
    file_url VARCHAR(500) COMMENT '访问URL',
    file_ext VARCHAR(20) COMMENT '文件扩展名',
    owner_id BIGINT NOT NULL COMMENT '上传人ID',
    owner_name VARCHAR(100) COMMENT '上传人姓名',
    version INT DEFAULT 1 COMMENT '版本号',
    is_latest TINYINT(1) DEFAULT 1 COMMENT '是否为最新版本',
    download_count INT DEFAULT 0 COMMENT '下载次数',
    tags VARCHAR(500) COMMENT '标签，逗号分隔',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_folder_id (folder_id),
    INDEX idx_owner_id (owner_id),
    INDEX idx_file_name (file_name)
);
```

### 3.3 文档版本表 (document_version)

```sql
CREATE TABLE IF NOT EXISTS document_version (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    file_id BIGINT NOT NULL COMMENT '文件ID',
    version INT NOT NULL COMMENT '版本号',
    file_size BIGINT COMMENT '文件大小',
    file_path VARCHAR(500) COMMENT '存储路径',
    file_url VARCHAR(500) COMMENT '访问URL',
    comment VARCHAR(500) COMMENT '版本说明',
    creator_id BIGINT NOT NULL COMMENT '创建人ID',
    creator_name VARCHAR(100) COMMENT '创建人姓名',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_file_version (file_id, version)
);
```

### 3.4 文档共享表 (document_share)

```sql
CREATE TABLE IF NOT EXISTS document_share (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    file_id BIGINT NOT NULL COMMENT '文件ID',
    share_type VARCHAR(20) NOT NULL COMMENT '共享类型: DEPARTMENT-部门, USER-个人, PUBLIC-公开',
    target_id BIGINT COMMENT '目标ID（部门ID或用户ID）',
    can_download TINYINT(1) DEFAULT 1 COMMENT '允许下载',
    can_print TINYINT(1) DEFAULT 0 COMMENT '允许打印',
    expire_time DATETIME COMMENT '过期时间',
    creator_id BIGINT NOT NULL COMMENT '创建人ID',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_file_id (file_id)
);
```

## 4. API设计

### 4.1 文件夹管理

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/doc/folders | 文件夹树 |
| POST | /api/doc/folders | 创建文件夹 |
| PUT | /api/doc/folders/{id} | 重命名文件夹 |
| DELETE | /api/doc/folders/{id} | 删除文件夹 |
| PUT | /api/doc/folders/{id}/move | 移动文件夹 |

### 4.2 文件管理

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/doc/files | 文件列表 |
| GET | /api/doc/files/{id} | 文件详情 |
| POST | /api/doc/files | 上传文件 |
| DELETE | /api/doc/files/{id} | 删除文件 |
| PUT | /api/doc/files/{id}/move | 移动文件 |
| PUT | /api/doc/files/{id}/rename | 重命名文件 |

### 4.3 版本管理

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/doc/files/{id}/versions | 版本历史 |
| POST | /api/doc/files/{id}/versions | 创建新版本 |
| PUT | /api/doc/files/{id}/versions/{vid}/rollback | 回滚版本 |

### 4.4 共享管理

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/doc/files/{id}/shares | 共享列表 |
| POST | /api/doc/files/{id}/shares | 添加共享 |
| DELETE | /api/doc/shares/{id} | 删除共享 |

### 4.5 搜索

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/doc/search | 搜索文档 |
